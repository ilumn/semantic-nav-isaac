# Security policy

Do not open a public issue containing credentials, private maps, camera frames,
robot network addresses, or host configuration. Report security-sensitive
findings privately to the repository maintainers through the hosting
platform's private vulnerability-reporting feature.

Only the current `main` branch is supported. Isaac Sim, ROS, NVIDIA drivers,
Python packages, and downloaded model files remain third-party components with
their own security policies and update channels.
