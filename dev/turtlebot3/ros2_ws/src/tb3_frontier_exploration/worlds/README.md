# Legacy world references

These SDF worlds are retained only as source references for scene dimensions,
target poses, and visual parity. They are not installed and are not supported
runtime inputs in the Isaac sibling.

- `warehouse_semantic_models.world`: original 4 x 6 metre semantic warehouse;
- `detector_test.world`: original compact perception layout.

The authoritative scene manifest and USD construction code live under
`dev/isaac_sim/scene`. Run the simulator with `dev/isaac_sim/run_sim.sh`.
